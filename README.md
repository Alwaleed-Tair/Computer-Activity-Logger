# Computer Activity Logger

برنامج صغير (سكربت Bash واحد: `cal.sh`) يعمل في الخلفية على Linux، وبموافقتك يسجّل **أي برامج شغّلتها ومتى بدأت ومتى انتهت وكم دامت**، ثم يعطيك ملخصًا وملف Excel.

**لا يسجّل أبدًا:** ضغطات المفاتيح، كلمات المرور، عناوين النوافذ، محتوى الشاشة أو الملفات، وسائط الأوامر. لا يرسل شيئًا عبر الشبكة، ولا يحتاج root، ولا يشتغل قبل موافقتك.

## التثبيت
لا يوجد تثبيت. تحتاج Linux (Ubuntu مثلًا) و Bash 4.3+ و`ps` و`awk` (موجودة افتراضيًا).

```bash
git clone https://github.com/Alwaleed-Tair/Computer-Activity-Logger.git
cd Computer-Activity-Logger
```

على ويندوز: استخدم WSL (Ubuntu). وانسخ المشروع داخل مجلدك في Linux (`~`) لا داخل `/mnt/c`.

## الاستخدام

| الأمر | وظيفته |
|---|---|
| `./cal.sh start` | يبدأ التسجيل في الخلفية (في أول مرة يعرض ما يُسجَّل ويطلب موافقتك بكتابة `yes`) |
| `./cal.sh stop` | يوقف ويحفظ كل شيء |
| `./cal.sh status` | هل يعمل؟ كم سُجّل؟ |
| `./cal.sh report` | ملخص في الطرفية + ملف `data/report.csv` لـ Excel |
| `./cal.sh autostart on` / `off` | يبدأ تلقائيًا عند تسجيل دخولك (خدمة systemd للمستخدم) / يلغي ذلك |
| `./cal.sh purge` | يحذف كل البيانات والموافقة (بعد تأكيد `yes`) |

جرّبه:
```bash
./cal.sh start
sleep 20 & sleep 40 &        # برامج تجريبية
sleep 60
./cal.sh stop
./cal.sh report
```

## الملفات (في `data/`)

- **`sessions.csv`** — جلسة لكل تشغيل: `Session,User,Start_UTC,End_UTC,Seconds,Status`. الحالة: `COMPLETED` (إيقاف عادي) أو `CRASHED` (مات البرنامج أو انقطعت الكهرباء؛ النهاية = آخر مرة رُصد فيها).
- **`processes.csv`** — صف لكل برنامج: `Session,PID,Name,Start_UTC,End_UTC,Seconds,Status`. الحالة: `ENDED` (رُصد وهو ينتهي) أو `STOPPED` (كان لا يزال يعمل عندما أوقفت التسجيل).
- **`report.csv`** — لكل اسم برنامج: عدد مرات التشغيل، مجموع الثواني، أطولها، متوسطها.
- ملفات داخلية: `.consent` و`.session` و`.pid` و`.lock` و`cal.log` (أخطاء إن وُجدت).

الأوقات كلها بتوقيت **UTC**. الملفات بصلاحية 600 والمجلد 700. ملفات CSV بترميز UTF-8 مع BOM فيظهر العربي صحيحًا في Excel.

## كيف يعمل (باختصار)

1. كل 5 ثوانٍ (`CAL_INTERVAL`) يأخذ لقطة بأمر `ps -u` لعملياتك فقط.
2. يقارنها باللقطة السابقة: عملية جديدة ← يبدأ يتابعها (وقت بدئها الحقيقي يأخذه من النظام)، وعملية اختفت ← يكتب لها صفًا واحدًا بمدتها. هوية العملية = **رقمها + وقت بدئها** (لأن Linux يعيد استخدام الأرقام).
3. المدد تُحسب من ساعة النظام الرتيبة `/proc/uptime`، فتغيير ساعة الجهاز لا يخربها.
4. نسخة واحدة فقط تعمل (قفل `flock`).
5. عند الإيقاف يكتب الصفوف للبرامج التي لا تزال تعمل (`STOPPED`) ويقفل الجلسة. وإذا مات البرنامج فجأة، يقفل الجلسة المقطوعة (`CRASHED`) عند التشغيل التالي.

يتجاهل افتراضيًا العمليات الروتينية (`bash` و`sh` و`systemd` و`dbus-daemon`...)، وكذلك عملياته المساعدة. للتغيير: `CAL_IGNORE="name1 name2" ./cal.sh start`.

## التشغيل التلقائي

`./cal.sh autostart on` ينشئ خدمة في `~/.config/systemd/user/` (بدون root) تبدأ عند **تسجيل دخولك** وتتوقف عند آخر خروج، وتعيد تشغيل نفسها إذا انهارت. هذا **ليس** بدء التشغيل مع تشغيل الجهاز: وقت بداية الجلسة في السجل هو وقت دخولك. تحتاج systemd (في WSL فعّل `systemd=true` تحت `[boot]` في `/etc/wsl.conf`).

## حدود معروفة

- **العمليات الأقصر من فاصل الفحص (5 ث)** تفوت غالبًا، وإذا التُقطت تُسجَّل بمدة تقارب الفاصل لا مدتها الحقيقية. استخدم `CAL_INTERVAL=1` لدقة أعلى.
- وقت النهاية هو وقت **اكتشاف** الانتهاء (قد يتأخر حتى فاصل واحد)، ووقت البدء بدقة ±1 ث.
- **مجموع الثواني في التقرير مجموع بسيط**: عمليات تعمل معًا (مثل 14 عملية للمتصفح) تتراكم، فهو ليس «وقت استخدامك للبرنامج».
- عند الانهيار تضيع صفوف البرامج التي كانت تُتابَع في تلك اللحظة (تظهر في الجلسة التالية كبرامج جديدة بوقت بدئها الحقيقي)؛ الجلسة نفسها تُقفل.
- اسم العملية تقتطعه النواة عند 15 بايتًا.
- المراقب يرى عمليات Linux التي في نفس النظام فقط (في WSL لا يرى برامج ويندوز).
